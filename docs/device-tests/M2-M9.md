# Device test checklist: Milestones 2 to 9

Run on your iPhone through an EAS development build (see M1 section 0). The backend runs with placeholder adapters, so audio is the development tone and the interview uses the scripted development LLM until real vendors are connected (`docs/runbooks/go-live.md`). Record Pass, Fail or Skipped for every step. On a failure capture a screenshot and the Metro log lines around it.

Never type real personal details into a development build. Use a fictional athlete.
