# Device test checklist: Milestone 1

Run on your iPhone through an EAS development build. Record the result for every step (Pass, Fail, Skipped) and capture what is listed under each failure. Send the filled-in file back, or paste it into the pull request.

## 0. Before you start (once)

1. Pick a development bundle identifier that you control, for example `com.<yourname>.avanvu.dev`, and set it: `eas env:create --name AVANVU_BUNDLE_ID --value <id> --environment development` (D-35).
2. From the repository root run `pnpm install`.
3. In `apps/mobile` run `eas build --profile development --platform ios`. Install the build on your iPhone from the link EAS gives you.
4. Start the dev server: `pnpm --filter mobile start`. Open the installed Avanvu app and connect to it.

Record: iPhone model, iOS version, build number.
